# Protect the Light – Demo Skeleton (Godot 4.3 / 4.7)

## Cách mở
1. Giải nén
2. Mở Godot 4.3 hoặc 4.7
3. Import project → chọn thư mục này
4. Bấm Run (F5)

## Điều khiển demo hiện tại
- WASD : Di chuyển
- Chuột : Xoay camera
- ESC   : Hiện/ẩn chuột
- Đuốc đang cháy và từ từ hết (demo)

## Mục tiêu demo
- Đi về phía ánh sáng xanh dương ở cuối map (Destination)
- Quan sát ánh sáng đuốc thay đổi theo độ bền

## Cấu trúc đã có
- Player di chuyển 3D + camera third-person
- Torch system (độ bền + OmniLight3D)
- HealthComponent + TorchComponent
- GameManager + NetworkManager (autoload)
- Môi trường tối + sương mù

Bạn có thể tiếp tục implement từ đây theo GDD.
